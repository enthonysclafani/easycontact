# EasyContact

Plugin di moduli per WordPress. È in corso l'adeguamento agli standard di qualità di EasyRankly.

Prima di qualsiasi modifica leggi `docs/piano-standard.md`: stato di partenza, standard di arrivo, decisioni aperte
(da chiedere, non da scegliere da soli) e fasi con le caselle da spuntare. Questo file verrà sostituito dal
`CLAUDE.md` completo al punto 1.1 del piano.

- Branch base: `Refactory`. Ogni sessione lavora su un branch proprio e apre una pull request verso `Refactory`.
- In locale il sito di sviluppo è in WordPress Studio (`~/Studio/form-a-caso`): i comandi WP-CLI sono `studio wp ...`.
